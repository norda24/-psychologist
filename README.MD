# Прототип информационной системы «Центр психологической помощи»

Desktop-приложение для автоматизации работы сотрудников центра психологической помощи. Система поддерживает разделение прав доступа (Администратор/Психолог), ведение логов безопасности, динамическое переключение тем оформления, валидацию входных данных, предотвращение подбора паролей (Brute-Force) и экспорт отчетов в формат CSV.

## 🛠 Стек технологий
* **Язык программирования:** Python 3.10+
* **Графический интерфейс (GUI):** Tkinter (встроенная библиотека Python)
* **Регулярные выражения (Валидация):** модуль `re`
* **Логирование и экспорт:** модули `os`, `csv`, `time`, `datetime`

## 📥 Как установить (по шагам)

### Шаг 1. Установка интерпретатора Python
Если у вас еще не установлен Python, скачайте его:
1. Перейдите на официальный сайт [python.org/downloads](https://python.org).
2. Нажмите кнопку **Download Python** (рекомендуется версия 3.10 или новее).
3. **Важно:** При запуске установщика обязательно поставьте галочку напротив пункта **«Add Python to PATH»** в самом низу окна.
4. Нажмите **Install Now** и дождитесь окончания установки.

### Шаг 2. Скачивание проекта с GitHub
1. Перейдите на страницу репозитория: `https://github.com`.
2. Нажмите зеленую кнопку **Code** в правой части экрана.
3. Выберите **Download ZIP** и распакуйте архив в любую удобную папку на компьютере.

## 🚀 Как запустить (по шагам)

### Вариант 1. Запуск через Проводник (самый простой способ)
1. Откройте папку с распакованным проектом.
2. Найдите файл с кодом приложения (например, `app.py` или `main.py`).
3. Дважды кликните по нему левой кнопкой мыши. Приложение откроется в отдельном графическом окне.

### Вариант 2. Запуск через Командную строку / Терминал
1. Откройте папку с проектом.
2. В адресной строке проводника (сверху, где написан путь к папке) сотрите всё, введите три буквы `cmd` и нажмите **Enter**. Откроется командная строка.
3. Введите команду для запуска приложения и нажмите **Enter**:
   ```bash
   python app.py
   ```

## 🔑 Данные для тестирования системы

При первом запуске вы можете использовать уже созданные тестовые учетные записи:

1. **Режим Администратора (полный доступ к CRUD-операциям):**
   * **Логин:** `admin`
   * **Пароль:** `Password1!`

2. **Режим Психолога (только просмотр и личное расписание):**
   * **Логин:** `psycho1`
   * **Пароль:** `User123!`

*Примечание: Вы также можете использовать кнопку «Регистрация терапевта» для создания новых пользователей. Пароль должен содержать не менее 8 символов (включая цифру, заглавную букву и спецсимвол). Регистрация email-адресов с содержанием подстроки `admin` в домене блокируется встроенной системой безопасности.*
